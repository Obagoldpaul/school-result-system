School Administration

Learn how to manage classes and oversee important school administration activities in Paul SchoolHub.

1. Class Management

The Class Management section allows authorised school users to organise classes, monitor student numbers and manage class progression.

Viewing Classes
  1. Open Class Management from your school navigation menu.
  2. Classes are organised into sections: Pre-Primary, Primary, Junior Secondary and Senior Secondary.
  3. Each class card displays the class name, section, number of students and current status.
Adding a New Class
  1. Open the Class Management page.
  2. Select Add Class.
  3. Enter the class name, for example, BASIC 1 or JSS 1.
  4. Select the appropriate section.
  5. Submit the form to save the new class.
Editing a Class
  1. Locate the class you want to update.
  2. Select Edit Class.
  3. Update the class name or section as necessary.
  4. Save your changes.
Activating and Deactivating Classes

Each class has an active or inactive status. Authorised users can change this status from the Class Management page.

  • Active: The class is marked as active.
  • Inactive: The class is marked as inactive.

Before deactivating a class, consider its current use in your school's operations.

2. Promoting Students

Class promotion allows a school to move active students from one class to another.

  1. Open Class Management.
  2. Select Promote / Graduate Students.
  3. Choose Promote as the action.
  4. Select the source class under From Class.
  5. Select the destination class under To Class.
  6. Review your selections carefully.
  7. Select Continue and confirm the browser prompt.
Important: Promotion moves all active students in the selected source class to the destination class. It is not an individual-student promotion process. Verify both classes before proceeding.

3. Graduating Students

The graduation option allows a school to mark all active students in a selected class as graduated.

  1. Open Class Management.
  2. Select Promote / Graduate Students.
  3. Choose Graduate as the action.
  4. Select the class whose students are graduating.
  5. Carefully review your selection.
  6. Select Continue and confirm the browser prompt.
Important: Graduation affects all active students in the selected class. Their admission status is changed to Graduated, and their student records are marked inactive. Confirm that you have selected the correct class before proceeding.

4. Managing Academic Sessions and Terms

Academic sessions and terms help schools organise their academic calendar and manage academic activities for different periods.

Accessing Academic Management
  1. Open your school dashboard.
  2. Select Academic Management from the navigation menu.
  3. The page displays the current academic session, available sessions and their terms.
Creating an Academic Session
  1. On the Academic Management page, select Create Session.
  2. Enter the academic session, for example, 2026/2027.
  3. Select Create Session to save it.

Creating a session does not automatically make it the current academic session.

Viewing and Managing Sessions

The Academic Sessions table displays the sessions created for your school and indicates which one is current.

  • Current: The session currently in use.
  • Inactive: A session that is not currently selected.

To view the terms belonging to another session, select Manage beside that session.

Creating Academic Terms
  1. Select the academic session you want to manage.
  2. Under the Terms section, select Create Term.
  3. Choose First Term, Second Term or Third Term.
  4. Enter the start date and end date if available.
  5. Select Create Term to save it.

Each term belongs to the academic session selected when it is created. The same term cannot be created twice within one session.

Making a Session Current

A session must have a First Term before it can become current. The Academic Management page makes a session current when one of its terms is set as current.

  1. Create the academic session.
  2. Select Manage beside the session.
  3. Create the First Term if it does not already exist.
  4. In the Terms table, select Set Current beside First Term.

The First Term and its academic session will then be marked as current.

Changing the Current Term
  1. Open Academic Management.
  2. Select the academic session containing the term.
  3. Locate the term you want to activate.
  4. Select Set Current.

The selected term becomes the current term. Its academic session also becomes the current session.

Understanding Term Status
  • Current: The term currently selected for academic operations.
  • Inactive: A term that is not currently selected.
  • Published: The term has been marked as published.
  • Not Published: The term has not been marked as published.
Important: Confirm the correct academic session and term before making changes. The current session and term determine the academic period used by relevant school operations.

5. Managing Departments

Departments help schools organise students into academic groups, particularly where different subject combinations are offered.

Accessing Department Management
  1. Open your school dashboard.
  2. Select Academic Management.
  3. Scroll down to the Departments section.
Creating a Department
  1. Select + Add Department.
  2. Enter the department name, for example, Science or Arts.
  3. Select Create Department.

Department names are required and cannot exceed 50 characters. Duplicate department names are not allowed within the same school.

Editing a Department
  1. Locate the department in the Departments table.
  2. Select Edit beside its name.
  3. Change the department name if necessary.
  4. Review the default elective subjects.
  5. Select the elective subjects you want associated with the department.
  6. Select Save Changes.
Configuring Default Elective Subjects

When editing a department, you can select default elective subjects using the available checkboxes.

These selections determine the elective subjects students in that department should receive automatically when the relevant registration process applies.

Note: Create your subjects before configuring default elective subjects for departments. Only active elective subjects belonging to your school are available for selection.

6. Managing Subjects

Subject Management allows schools to create subjects, organise them by academic level, identify compulsory and elective subjects, and assign subjects to classes and individual students.

Accessing Subject Management

Open the Subjects section from your school navigation.

Creating a Subject
  1. Open the subject list.
  2. Select + Add New Subject.
  3. Enter the subject name.
  4. Enter the subject code, where applicable.
  5. Select the appropriate school level.
  6. Select a parent subject if the subject belongs to another subject.
  7. Tick the elective option if the subject is an elective.
  8. Select Save Subject.
Important: Available school levels depend on your school's configuration. Primary schools can create Primary subjects, secondary schools can create Secondary subjects, while combined schools can use both levels. Subject names must be unique within the same school and level.
Understanding Subject Types
  • Compulsory Subjects: Subjects that are not marked as electives.
  • Elective Subjects: Subjects identified as electives and available for student elective selection when assigned to the relevant class.
Understanding Parent Subjects

A parent subject allows a subject to be associated with another subject. For example, a specialised subject can be linked to a broader subject.

The parent subject must belong to the same school and academic level.

Editing, Activating and Deactivating Subjects
  1. Open the subject list.
  2. Use the available filters to find a subject.
  3. Select Edit to modify its details.
  4. Select Deactivate to make an active subject inactive.
  5. To restore an inactive subject, open View Inactive Subjects and select Activate.

Deactivating a subject changes its active status; it does not delete the subject record.

Assigning Subjects to Classes

Before students can receive subjects through their classes, the relevant subjects must be assigned to those classes.

Individual Assignment
  1. Open the subject list.
  2. Select Assign Subject to Class.
  3. Select the class.
  4. Select the subject available for that class level.
  5. Select Save Assignment.
Bulk Assignment
  1. Open the bulk assignment page.
  2. Select the class.
  3. Tick all the subjects you want assigned.
  4. Use Select / Deselect All when appropriate.
  5. Select Assign Selected Subjects.
Subject-level restrictions: Pre-Primary and Primary classes use Primary subjects. Junior Secondary and Senior Secondary classes use Secondary subjects. The assignment pages filter subjects according to the selected class.
Viewing Class-Subject Assignments
  1. Open Class - Subject Assignments.
  2. Filter by Group / Section or Class if necessary.
  3. Select Filter to apply your selection.
  4. Review the subjects assigned to each class.

You can also select Reset to clear the filters.

Removing a Class-Subject Assignment
  1. Find the subject under the relevant class.
  2. Select Unassign.
  3. Review the subject and class displayed.
  4. Select Yes, Unassign to confirm.

Unassigning removes the relationship between the subject and the class. It does not delete the subject from the school's subject records.

Managing Student Elective Subjects

Class-subject assignments and individual student elective assignments are two different operations.

Viewing Elective Assignments

The Elective Assignments page displays active students, their admission numbers, classes, departments and currently assigned elective subjects.

You can filter the list by:

  • Class
  • Department
Assigning Electives to an Individual Student
  1. Find the student on the Elective Assignments page.
  2. Select Assign / Edit.
  3. Review the student's name, admission number, class and department.
  4. Select the appropriate subjects under Available Elective Subjects.
  5. Select Save Elective Subjects.
Important: Saving an individual student's elective selections replaces their previous elective selections with the newly selected ones. Only active elective subjects assigned to the student's class are available.
Configuring Department Default Electives

Schools can configure default elective subjects when editing a department in Academic Management.

  1. Open Academic Management.
  2. Locate the Departments section.
  3. Select Edit beside the relevant department.
  4. Select the required subjects under Default Elective Subjects.
  5. Select Save Changes.

After configuring the defaults, open Elective Assignments.

  1. Filter by the relevant department.
  2. Optionally filter by class.
  3. Select Apply Department Defaults.
  4. Confirm the operation.
How department defaults work: The system adds eligible default elective subjects to students in the selected department. A subject is added only when it is assigned to the student's current class. Existing elective assignments are preserved; they are not removed or replaced.

7. Managing School Settings

School Settings allows authorised school administrators to manage the school's contact information, payment details, principal information, branding and public registration preferences.

Accessing School Settings
  1. Open your school dashboard.
  2. Navigate to School Settings.
  3. Review the information displayed on the page.

Access requires the school_settings.manage permission.

Updating School Information

You can update the following information:

  • School Name
  • School Logo
  • School Address
  • Phone Number
  • Email Address

To update the school logo, select the appropriate image file using the School Logo field.

Setting Up the School Payment Account

The School Payment Account section contains the bank details displayed to students and parents when making school fee payments.

Enter the following information:

  1. Bank Name: The school's bank.
  2. Account Name: The name registered on the school bank account.
  3. Account Number: The school's payment account number.
Important: Check the bank details carefully before saving. Incorrect payment information may cause students and parents to transfer fees to the wrong account.
Principal Information

You can enter the principal's name and upload the principal's signature. These details can be used in school documents and report cards where applicable.

School Branding Settings

Depending on your subscription package, you may be able to customise the following:

  • Primary Colour: The main school branding colour.
  • Secondary / Accent Colour: The complementary branding colour.
  • Report Card Heading: The heading displayed on student report cards.
  • School Motto: The school's motto.
  • Show Class Position: Controls whether students' class positions appear on report cards.
Package restrictions: The branding options available depend on your school's subscription package. Basic and Standard packages have certain branding fields restricted, while Premium retains all branding fields.
Managing Public Registration

The Registration Settings section allows authorised administrators to control whether the school accepts public registration applications.

  • Allow Student Registration: Enables or disables public student registration applications.
  • Allow Teacher Registration: Enables or disables public teacher registration applications.

Tick the relevant checkbox to enable registration or untick it to disable registration.

Important distinction: These settings control public registration applications. They do not replace the internal student and teacher registration processes carried out by authorised school administrators.
Viewing and Sharing Registration Links

When an active primary domain is configured for your school, the Public Registration Links section displays the following:

  • Your school's primary domain.
  • Student Registration Link.
  • Teacher Registration Link.

To share a registration link:

  1. Locate the appropriate registration link.
  2. Check whether registration is marked Enabled or Disabled.
  3. Select Copy Link.
  4. Share the copied link with the appropriate applicants.
Note: If no active primary domain is configured, the registration links will not be displayed. Contact your platform administrator for assistance with domain configuration.
Saving School Settings

After making your changes, scroll to the bottom of the page and select Save School Settings.

The system will save the changes and display a confirmation message when the update succeeds.

Recommendation: Review your school's contact information, payment account and registration preferences regularly to ensure that students, parents and applicants receive accurate information.

8. Managing Registration Applications

Registration Applications allows authorised school staff to review applications submitted through the school's public student or teacher registration links. This is different from registering students and teachers directly through the school dashboard.

Accessing Registration Applications
  1. Open your school dashboard.
  2. Select Registration Applications from the navigation menu.
  3. Review the list of submitted applications.
Understanding the Applications List

The applications table displays the applicant's name, role, username, email, requested class or department (for students), application status and submission date.

Select View beside an application to examine the full details.

Reviewing an Application

The details page provides the information submitted by the applicant. Depending on the application type, this may include:

  • Account and personal information.
  • Passport photograph, if provided.
  • Requested class and department for student applicants.
  • Guardian and health information for student applicants.
  • Qualifications, experience and certificate for teacher applicants.
  • Bank information for teacher applicants.
Approving an Application
  1. Open the application using the View button.
  2. Carefully review the submitted information.
  3. Select Approve Application.
  4. The system creates the applicant's school account and corresponding student or teacher profile.
  5. The application status changes to Approved.
Important: Approved accounts are initially created without a usable password. The system sends a password-setup email to the applicant so they can create their password. Ensure the applicant's email address is correct.
Rejecting an Application
  1. Open the application you want to reject.
  2. Select Reject Application.
  3. Enter a reason for rejecting the application.
  4. Select Reject Application in the confirmation dialog.

A rejection reason is required. The application remains stored for reference, but no school account or student or teacher profile is created.

Viewing Reviewed Applications

Applications that have been approved or rejected retain their review history. Their details page displays the application status, the person who reviewed it, the review date and time, and the rejection reason where applicable.

Confidentiality: Applications may contain personal, health and financial information. Review these details only for legitimate school administrative purposes and handle them confidentially.

9. Teacher Management

The Teacher Management page provides access to teacher records, payment accounts, registration and teacher availability settings.

Managing Teacher Availability

Teacher Availability allows authorised school staff to configure the days and times individual teachers are available for timetable scheduling.

Accessing Teacher Availability
  1. Open Teacher Management from the school navigation menu.
  2. Select the Teacher Availability button at the top of the page.
  3. The page displays the availability records already configured for your school.
Adding Teacher Availability
  1. Locate the Add Teacher Availability form.
  2. Select the teacher whose availability you want to configure.
  3. Select the applicable day of the week.
  4. Enter the starting time under Available From.
  5. Enter the ending time under Available Until.
  6. Select Add Availability to save the record.
Viewing Configured Availability

The Configured Teacher Availability table displays the teacher's name, day, starting time and ending time. Use this information when planning the school's timetable.

Editing or Deleting Availability
  • Select Edit beside an existing record to update the teacher, day or available time.
  • Select Delete to remove an availability record that is no longer needed.
Important: Configure teacher availability carefully before generating or managing timetables. Availability records help guide timetable scheduling.
Access and permissions: Some school administration activities are restricted to authorised users. If an option is unavailable, contact your school's administrator to confirm your account permissions.
